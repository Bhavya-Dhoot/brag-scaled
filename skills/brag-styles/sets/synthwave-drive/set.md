# Synthwave Drive

Synthwave: a neon grid road at night, a striped sun on the horizon, and claims flying past as road signs.

- **Asked for as:** synthwave, retrowave, outrun, 80s neon, vaporwave
- **Best for:** music, games, creator drops, developer side projects, retro tech. A novelty for B2B
- **Palette:** night `#12052B`, magenta `#FF2E97`, cyan `#21E6F0`, grid violet `#7A2BFF`, sun from `#FFB03A` to `#FF2E97`
- **Type:** Archivo Black skewed -8 degrees with a chrome gradient fill and a magenta outline; JetBrains Mono for readouts
- **Texture:** a perspective grid floor scrolling toward the viewer, a striped setting sun, scanlines; glow on headings only
- **Signature move:** the road. The grid scrolls on the beat and each claim is a road sign that grows from the horizon and flies past; the proof is a dashboard readout climbing
- **Transitions:** a horizontal tracking glitch, then the horizon wipes up
- **Sound:** `pulse` bed at 110 BPM; `whoosh` on each sign, `ping`, `glitch`
- **Watch out:** glow eats legibility: body text stays plain white. Tie the grid speed to the tempo

## Reference kit (open only what you need)
- `frames/f1-f4.webp`: the hook, the signature move mid-way, the proof, the end card.
