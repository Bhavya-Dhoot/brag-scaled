# Y2K Chrome

The year-2000 desktop: chrome type, glossy orbs, sparkles and windows popping open.

- **Asked for as:** Y2K, 2000s, chrome, frutiger aero, cyber-pop, early web
- **Best for:** fashion, music, Gen Z consumer apps, creator drops, nostalgia campaigns. Weak for B2B
- **Palette:** ice `#BFE6FF`, cobalt `#2440FF`, hot pink `#FF4FD8`, lime `#B6FF3B`, white, and chrome (a silver gradient `#F4F7FA` to `#8FA3B8` and back)
- **Type:** Bricolage Grotesque 800 stretched wide (`scaleX(1.25)`) with a chrome gradient and a cobalt outline; JetBrains Mono for system text
- **Texture:** glossy orbs with a white highlight, four-point sparkles, plain desktop windows with a title bar, dotted grids
- **Signature move:** the desktop. Windows pop open in a stack, a glossy orb bounces between them, a striped bar downloads to 100% and sparkles burst
- **Transitions:** a window maximises to fill the frame
- **Sound:** chip arpeggios over `pulse` at 128 BPM; `pop`, `chime`, `payout`
- **Watch out:** draw generic windows only: no real operating-system logos or wallpapers

## Reference kit (open only what you need)
- `frames/f1-f4.webp`: the hook, the signature move mid-way, the proof, the end card.
- `ref/look.html`: a ten-second working sample of this look: the entrance, the signature move with a performer, a counted proof and the end card, every frame a pure function of time. Lift the mechanism; replace every word and number. It loads fonts from `../../../../motion-kit/fonts/`.
