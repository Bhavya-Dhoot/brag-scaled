# Illuminated Manuscript

Vellum, gold-leaf drop caps, marginalia creatures: the product written up as a medieval chronicle.

- **Best for:** knowledge tools, writing apps, docs products, AI that "writes", anything with a history to tell
- **Palette:** vellum `#efe2c3`, iron-gall ink `#2a1f16`, rubric red `#a8231d`, lapis `#264a8c`, burnished gold `#c79a2b`
- **Type:** UnifrakturMaguntia for headings only (never body), IM Fell English for body
- **Texture:** vellum grain, ruled lines, pricking holes along the margin, foxing spots
- **Signature move:** a drop cap illuminates. Its outline is inked first, then gold leaf burnishes in with a glint, then the text is written line by line as if by quill.
- **Transitions:** a vellum page turn, with a marginal creature peeking around the gutter
- **Sound:** a quill scratch (in the Doodle family), lute and recorder in the Dorian mode, a bell on each gilded letter
- **Watch out:** blackletter is unreadable to most viewers. Use it for single words, never for claims.
