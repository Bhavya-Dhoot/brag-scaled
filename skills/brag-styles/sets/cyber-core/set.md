# Cyber Core

Cybercore: a black terminal, falling code, a HUD frame, and an alert that flips from red to secured.

- **Asked for as:** cybercore, cyberpunk, hacker, terminal, matrix, HUD, neon tech
- **Best for:** security, developer tools, AI infrastructure, games, hacker-culture launches
- **Palette:** black `#050608`, terminal green `#32FF7E`, cyan `#00E5FF`, alert magenta `#FF2BD6`, dim green `#0B3D24`
- **Type:** JetBrains Mono for almost everything; Archivo Black for one headline word
- **Texture:** falling code columns, a HUD frame with corner brackets, scanlines, hex readouts, a thin grid
- **Signature move:** the breach and the lock. A terminal types a command, a reticle sweeps and locks onto the claim, a magenta alert flips to green SECURED and a hex counter resolves to the number
- **Transitions:** a glitch tear, then the next screen decodes from random characters
- **Sound:** `pulse` or `phonk` bed at 130 to 140 BPM; `type`, `ping`, `lock`, `glitch`, `alert`
- **Watch out:** green on black shimmers at small sizes after encoding: keep body text 28 px or larger. Do not imitate a real intrusion or a real company's console
